# HTML-Inserts fuer Bootstrap

`member-cards-bootstrap.html` ist eine eigenstaendige Bootstrap-5-Vorlage fuer
einen WordPress-Block **Individuelles HTML**. Sie nutzt dieselbe Bild-,
Text- und Bewegungsgestaltung wie die dynamischen Mannschaftskarten, ohne PHP
oder JavaScript.

Zum Bearbeiten pro Karte nur diese fuenf Werte ersetzen:

1. `href` und `aria-label`
2. `src` und `alt` des Bildes
3. Dienstgrad
4. Name
5. Funktion bzw. Dienststellung

Die Vorlage setzt voraus, dass Bootstrap 5 im aktiven Theme geladen ist.
